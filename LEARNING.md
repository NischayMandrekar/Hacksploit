# Learning Journal

Tracks what you actually understand about this codebase versus what
you've only seen an agent do. This file exists because heavy AI-assisted
coding makes it easy to ship code you don't understand — and worse, to
feel like you understand it. This is the record that survives after a
session ends, so understanding compounds instead of evaporating.

This is about *your* understanding, not the project's status —
`PROJECT_PLAN.md` tracks what's built; this tracks what you can actually
explain, unaided, without an agent finishing your sentences.

## Confidence Map

Per topic/module, one of: **Solid** (could explain and modify it without
help), **Shaky** (recognize it, couldn't rebuild it from scratch),
**Bluffing** (have used it, couldn't actually explain why it works).

Be honest here, specifically about "Bluffing" — that tag is the whole
point of this file. Update it after each `/learn` session and whenever
you notice a gap while doing real work.
